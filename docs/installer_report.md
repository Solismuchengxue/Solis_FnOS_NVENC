## HEVC 与外挂字幕有限播放

### 素材来源与属性

只读探测限定在影视登记的四个媒体库及其子目录，不跟随符号链接。新增测试素材前，共 1,308 个常规视频：1,306 个 H.264、2 个 HEVC，没有外挂 SRT／ASS；访问、探测和身份检查无错误。另有 7 个 `.part` 文件未纳入，内容与完整性未验证。

既有两份 HEVC 分别为 Main 8-bit、Main10 10-bit，但流和开头 16 帧缺少色彩传递标记，SDR 属性仍未验证。随后在用户选定的 `Solis_SDR_Test/Main8/`、`Main10/` 准备两份自生成 MP4 和四份匹配字幕，不使用私人影片或第三方影视样本。

| 自生成视频 | 已核对属性 | SHA256 |
| --- | --- | --- |
| `solis_hevc_main_sdr.mp4` | Main，8-bit，`yuv420p` | `fe56c81134021deabb44aac6b823f63c240cea3be698f42e2cd6876d9c030cb7` |
| `solis_hevc_main10_sdr.mp4` | Main 10，10-bit，`yuv420p10le` | `50a8560606f294cfaaf3de38a8f9b53ad7b93139858245da88da640e338312d7` |

共同参数为 1920×1080、24 fps、180 秒、AAC 48 kHz 双声道；容器和 HEVC VUI 的原色、传递函数、矩阵均为 BT.709，有限范围。本机 FFmpeg 9.0 核对每份 4,320 帧和完整软件解码；Main10 灰阶超过 256 个采样值并含低两位信息。

六份素材共 8,905,538 字节，SHA256 传送读回一致。字幕为 UTF-8 无 BOM，完整解析；计时、运动标记、每秒闪烁／提示音用于有限观察，ASS 添加两行、颜色和粗体交替。为适应既有 3 MB 文件过滤调整了自生成 Main8 编码质量，未改媒体库设置。素材不属于安装载荷或恢复依赖。

### 用例结果

两个播放工作包开始前分别取得当次测试窗口确认。各用例执行单路原生 720p、一次人工跳转并继续，分别取得新声音确认。

| 用例 | 输入与字幕 | 有限结果 |
| --- | --- | --- |
| 既有 HEVC Main | 1080p、8-bit，色彩未确认，无外挂 | 通过：720p 编码绑定，声音正常、无明显不同步 |
| 既有 HEVC Main10 | 720p、10-bit，色彩未确认，无外挂 | 通过：720p 编码绑定及新声音确认；早先无编码会话的原画阶段不计入 |
| 自生成 Main SDR | 1080p、BT.709、8-bit，字幕关闭 | 通过：720p 编码绑定、一次快进和当次声音／同步确认 |
| 自生成 Main10 SDR | 1080p、BT.709、10-bit，字幕关闭 | 通过：720p 编码绑定和新确认；初次字幕错误阶段不计入 |
| 外挂 SRT | 同一 Main SDR，明确选择本片 UTF-8 SRT | 通过：客户端 DOM 字幕层，中文／英文／数字可读，跳转后时序和人工同步确认 |
| 外挂 ASS | 同一 Main SDR，明确选择本片 ASS | 通过：客户端独立画布，两行中文、白／黄、普通／粗体交替及人工同步确认 |

各例通过片源文件设备号／inode、影视服务祖先链、唯一候选库映射以及该 PID 的 NVIDIA H.264 1280×720 编码会话直接绑定。自生成四例浏览器实际视频尺寸为 1280×720；SRT 的 095 秒事件对应约 98 秒画面，ASS 的 070 秒事件对应约 72 秒画面，均处于配方有效区间。

这些结果只证明当次显示和人工可接受同步，不代表逐帧同步精度、完整色彩保真或复杂影片性能。既有片源采样时瞬时编码／解码利用率及平均 FPS 为 0，不能证明持续吞吐；编码会话也不能证明硬件解码。代理未独立听音频。
