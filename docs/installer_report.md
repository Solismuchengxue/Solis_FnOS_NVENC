## 构建与身份

公开构建只读取仓库、[固定公开来源](build_sources.json)和[依赖版本](build_packages.txt)，不依赖私人镜像、旧候选或 Codex 工件。六次制品均为 16,516,408 字节，SHA256 `88e48674062ee5ef71864a2619324772bc856fec78c0d4793920fa7d4c15cd57`；未改写合同放行。

原单库控制器 SHA256 为 `1250a7a648e9bc94709d250f11e11ee8b1447bdf3b70ff6356cb0762bd78f1cf`。固定输入、补丁及运行身份保留；源码发行不包含 nonfree 库、驱动、私人影片或过程材料。

限定源码复审和当时的 Python AST、Bash parser、材料身份及文档检查通过。ShellCheck 当时不可用；解析与隔离测试不替代真实 systemd、NVIDIA 或 NAS 验证。需要私人材料的 `verify_materials.py` 不属于公开安装链。

## 有限现场结果

现场操作在当次维护窗口与无人播放确认后执行。重启后启动钩子记录准备完成，服务实际加载候选；原 15 个容器以原身份和重启策略恢复。普通影片原生 720p 完成一次跳转并继续，用户当次确认“声音正常，无明显不同步”；代理未独立听音频。播放验证绑定真实 GPU 子进程身份、祖先关系及库映射。

退出播放器后卸载本工具注入和启动配置，恢复原 6 文件工具。因旧 `/run` 配置随重启消失，收尾使用新 boot 合同重新核对并恢复旧可用库与配置；实际库 SHA256 `3d7e7e241715fb6a3468a4d47d0fdaef3e6b79cecc3d3bb1f6d3118fac265367`，服务环境与原 drop-in 一致，持久 96 覆盖和本工具启动命令撤销。结束时服务 active，仅原历史 90 生效；没有第二次整机重启。

恢复归档当时下载核对，20 个成员及清单通过；本地旧归档已按用户要求退役，现场 `/var/lib` 恢复状态不受本次整理影响。传输、权限拒绝和无效属性检查均未当作通过证据，恢复结论来自已核对的实际 root 读回。另有非本轮 GPU 进程，不能据此称整台 NAS 空闲；本轮播放退出及卸载消费者门通过。

## 保留限制

完整原版功能对等 **FAIL**。厂商完整对应源码、生产 AC4 默认消费者、其他格式、并发、长期稳定性及任意未来升级仍有缺口，具体结论见[来源与边界](source_and_evidence.md)。一次整机重启和有限播放不构成长期验收。

本报告不提供新的运行或发布授权。当前使用入口见 [README](../README.md)，维护与恢复条件见[维护说明](maintenance.md)；本轮收敛不改变既有 `v0.1.0` 标签或首版现场结论。
