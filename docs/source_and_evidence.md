## 必要旧结论

以下为截至 2026-10-10 的既有有限检查，保留结论以免误判，未在文档整理中重跑。计数及缺失 codec 名单见[检查记录](historical_checks.json)。

| 检查 | 保留结论 | 限制 |
| --- | --- | --- |
| 原组件与驱动 | 普通 H264/AAC 短测因组件要求 API 13.0、驱动提供 API 12.1 而失败 | 候选独立转码成功不等于原生服务加载成功 |
| 早期短测 | 48 项 GPU、字幕、HLS、AC4、合成音轨检查通过；13 项波形对照一致 | 约 1～6 秒，不代表持续播放或全格式支持 |
| 保存库的 CPU 对照 | 21 项：17 PASS、4 REVIEW、0 FAIL，新旧输出一致 | FDK/libdca 对照说明统一阈值不适用于全部音频；不能推定解码器缺陷、标准符合性或主观音质 |
| 原单库播放与恢复 | 普通影片单路 720p、一次跳转、真实 GPU 子进程映射和新的人工声音确认通过，结束恢复旧可用版本 | 只属于完成报告记录的当次工作包 |
| 完整原版功能对等 | **失败（FAIL）**：缺 10 个 encoder、8 个 decoder 名称 | 540 个共有 descriptor ID 一致、缺导出符号为 0 及短测成功都不能关闭此缺口；BRAW/R3D 属于非目标 |

后续公开安装器的干净构建、重启、卸载恢复和 HEVC／字幕有限播放结果统一由验收报告维护，不改写原单库合同中的旧状态。

## 未关闭的技术限制

### AC4 与对应源码

既有样本能够解码，但厂商默认 raw 读包边界错误，生产 AC4 默认消费者问题仍未关闭。旧 demux、多库和配套实验能力已退役，其局部结果不属于现行支持承诺。厂商完整对应源码仍缺失。

### 编译与未测路径

构建需要 FFCodecParser 类型修正、AC4 parser/decoder 双注册检查，以及 SVT-AV1 encoder 开发包。成功编译不能关闭 33 项警告；内存、栈风险及 ASan/UBSan、FATE、模糊测试仍未完成。

VVC scaled inter、FFV1 float32、LCEVC BSF、UtVideo 10/16-bit 等未测路径不能宣称通过。硬件解码、服务端字幕烧录、HDR、复杂字幕、并发、持续吞吐和任意未来版本兼容仍未验证；长期稳定性由用户继续观察。

### 运行与人工体验

运行库使用已核对可执行、可映射的 `/opt` 路径，`noexec` 的 `/run` 只保存环境及临时状态。恢复目标是当次实际可用库与配置，不能盲用旧开机状态或假定总是恢复官方库。恢复官方映射不代表官方组件支持当前驱动的 GPU 转码。

已测 HEVC／SDR／外挂字幕只证明所测素材的单路有限播放和客户端字幕显示。编码会话不能证明硬件解码，客户端字幕层不能证明服务端烧录；代理没有独立听音频。字幕自动选择错误及旧工作包容器变化的原因仍未知，具体现场问题见验收报告。

## 保留材料与权威

公开安装依赖仓库和固定公开来源，现场恢复依赖 NAS 自身的恢复状态。本地保留四项源码缓存、当前库与身份文件、基线库，共七项固定材料；获批验收素材另存忽略目录，均按[材料管理](maintenance.md#目录与材料管理)处理。

旧冻结镜像、试验归档、过程日志、旧报告和计划已退役，不再建立历史目录或过程副本。当前代码、两份正式补丁、固定合同、必要检查记录、架构图与合同引用的完成报告保留。

完成报告正文是固定历史证据，按原工作包理解，其中私人包与临时材料已退役，不能当作现行安装步骤。当前恢复统一使用现行工具，源码与运行接入也分别核对，不能由本地整理推导现场已更新。

过去的批准只对应过去工作包。后续运行、重试、发布或清理以人的当次直接授权和[项目规则](../AGENTS.md)为准。
