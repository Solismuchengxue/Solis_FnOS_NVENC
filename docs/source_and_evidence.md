## 必要验证结论

以下结论来自截至 2026-10-10 的有限检查，未在本次整理中重跑。

| 检查范围 | 保留结论与限制 |
| --- | --- |
| 原组件与驱动 | 同一普通 H264/AAC 影片的短独立测试因组件要求 API13.0、驱动提供 API12.1 而失败；候选独立转码成功不等于原生服务已加载 |
| 早期短测 | 48 项 GPU、字幕、HLS、AC4 和合成音轨检查通过；13 项波形对照一致。时长约 1～6 秒；详细计数及缺失 codec 名单保留在[有限检查记录](historical_checks.json) |

| 单库原生播放与恢复 | 普通影片原生 720p、一次跳转并继续、真实 GPU 子进程候选映射及当次人工声音确认通过；结束恢复当次旧可用版本，固定合同证据见完成报告 |

| 完整原版功能对等 | **FAIL**：缺 10 个 encoder、8 个 decoder 名称。540 个共有 descriptor ID 一致、缺导出符号 0 和短测成功均不关闭此缺口；BRAW/R3D 属于非目标 |

## AC4 与编译限制

历史 AC4 检查表明：样本能够解码，但厂商默认 raw 读包边界错误，生产 AC4 默认消费者问题仍未关闭。旧上游 demux、多库和媒体实验能力已退役；其局部通过结论不属于现行安装链的支持承诺。厂商完整对应源码仍缺失。

构建需要 `FFCodecParser` 类型修正和 AC4 parser/decoder 双注册门；SVT-AV1 需要 encoder 开发包。成功编译不关闭仍存在的 33 项警告；内存、栈风险及 ASan/UBSan、FATE、模糊测试未完成。VVC scaled inter、FFV1 float32、LCEVC BSF、UtVideo 10/16-bit 等未测路径不能宣称通过。

## 恢复与证据边界

运行库放在核对过可执行、可映射的 `/opt` 路径；`noexec` 的 `/run` 只用于环境与临时状态。恢复目标是当次实际可用库与配置，不能盲用旧 boot 或假定一定恢复到官方库。2026-10-11 新工作包实际核对官方基线映射及旧可用兼容库恢复，结论见安装器报告；恢复官方映射不代表官方组件已支持当前驱动的 GPU 转码。

2026-10-11 已完成既有两份 HEVC 的有限播放，随后完成两份自生成 BT.709 Main／Main10 SDR，以及同一 Main 片配外挂 SRT／ASS 的原生 720p、一次跳转、实际候选库与 NVIDIA 编码会话绑定及当次人工确认，见[安装器报告](installer_report.md)。仅覆盖所测素材、单路播放及客户端字幕显示；硬件解码、服务端字幕烧录、HDR、复杂字幕、未覆盖格式、并发、长期稳定性及任意未来升级仍 **NOT_VERIFIED**。字幕初次自动选择的错误提示和旧容器变化的原因仍 UNKNOWN，代理未独立听音频。已发布首版的重启通过不改写早期单库合同中的重启未验证状态；当前现场状态需要带时间的实际读回。
