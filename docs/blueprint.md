# Solis_FnOS_NVENC 项目蓝图

## 状态与当前结论

状态：现行项目意图基线，2026-10-11。唯一权威为本文件。正式维护内容已精选收纳，不依赖 Codex 临时工件目录；公开首版的有限交付结论见[安装器报告](installer_report.md)，材料、构建、运行和长期启用分别判定。

## 问题、目标用户与价值

现有 fnOS 原生影视 FFmpeg 与 Tesla P4 / R535 环境之间存在 NVENC 兼容问题，影响普通电影、电视剧的 GPU 转码观看。目标用户为身份合同覆盖的设备所有者及公开源码使用者，需要可追溯、可复现、可检查且可回退的兼容方案。

## 目标结果与成功标准

- 固定来源、版本和补丁能够被准确说明；构建方法可由保存的来源和参数复现。
- 制品身份、兼容性限制和脱敏证据可追溯，安装和回退不覆盖官方组件或影响无关服务。
- 面向明确测试范围，原生影视 GPU 转码、播放、跳转续播和音画体验达到用户可接受结果；格式集合、长期稳定性时长和推广门槛目前为 `UNKNOWN`，不能默认全格式通过。
- 运行接入与持久启用分别取得对应授权和验证后，才可作该层交付声明。
- 系统升级后，用户可通过简短入口检查兼容、重新部署、看状态和回退，不必每次重编译或修改源码。未知版本明确拒绝，重新冻结升级后的实际基线；官方已兼容时提示无需兼容库。
- 公开源码用户通过 SSH 编号菜单从固定公开来源自行构建、安装、更新、暂停和卸载；不分发许可受限制品。每次影视服务启动重新检查，失败清除自有注入，按本次开机建立恢复记录。公开首版先通过有限现场重启和恢复验收。

## 范围

当前公开单库的固定版本和来源、源码补丁、可重复构建、兼容性检查、安装与回退、制品校验及必要验证结论。维护对象是应用层 FFmpeg/NVENC 兼容方案，与已有 Solis_Pvescript 工程分离。

## 非目标

不开发新的影视产品；不接管 PVE/VM 创建、GPU 驱动、Toolkit、License；不分发 NVIDIA 受限驱动或 nonfree 库；不保存秘密或私人影片；不承诺 BRAW/R3D 或任意版本兼容；不借初始化扩大运行权限；不维护 AC4 demux、多库及旧 CPU／音频对照实验能力。生产 AC4 默认消费者问题仍未关闭。

## 约束、依赖与 UNKNOWN

- 面向用户当前 fnOS / Tesla P4 / R535 环境，不假定其他主机、版本或未测路径可用。
- 依赖上游 FFmpeg/NVENC 接口与已有官方影视组件；相关许可和再分发条件需在实际收纳源码或制品前核对。
- 假设：独立兼容库方案值得作为小型维护工程继续评估；这不是完整原版功能对等或长期使用已通过的结论。
- 固定源码、补丁与当前候选身份及其已知许可限制已记录在[来源与边界](source_and_evidence.md)。固定环境两次构建已闭合，见[安装器报告](installer_report.md)。`UNKNOWN`：厂商对应源码、部分材料再分发条件、未测格式、跨版本兼容和长期稳定性。关闭条件是对应直接证据而不是一次播放成功。
- 维护假设：官方可能长期不提供所需兼容修复，因此准备重复使用的有限工具；这不是官方永远不会修的事实或任意未来版本可用的承诺。
- [来源与边界](source_and_evidence.md)保存必要来源与证据边界；当前工程、制品、运行和长期启用不得合并为一个状态。
