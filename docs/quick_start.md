# 已安装工具的快速使用

本页随 v0.1.1 工具安装，提供离线短说明。完整安装、准备条件、菜单与卸载手册在源码根目录的 README.md；历史报告不作为安装命令入口。

首版适用 fnOS 1.2.0701 / GRID P4-4Q / R535 535.309.01，仍须通过实际文件身份检查。源码目录运行 `bash fnos-nvenc.sh`；安装后运行 `sudo bash /opt/solis-fnos-nvenc/tool/runner.sh`。密码只在标准 sudo 提示中输入。

使用顺序：1 检查 → 2 安装 → 在影视服务器设置开启 GPU 加速转码，首选 GPU 明确选择 NVIDIA GP104GL [Tesla P4] → 原生 720p 播放、一次跳转并继续 → 保持播放时选 5，确认声音和同步后输入 `AUDIO_OK`。库已加载不能代替应用开关或真实 GPU 进程核对。任何服务变更前确认所有人退出播放与转码，包括直接播放；提示时输入 `IDLE`。

6 暂停并恢复当次开机基线；暂停后选 3 更新工具，检查通过才选 2 再启用。卸载先选 7 核对补丁恢复，再选 8 卸载工具。恢复未验证、身份漂移或消费者不明时停止删除，保留记录。

当前工具损坏但上一版完整时，从保留的源码目录运行 `sudo bash fnos-nvenc.sh restore-tool`。历史 `check/deploy/status/rollback` 保留；deploy 仅临时接入，持久补丁启用时不能混用。
