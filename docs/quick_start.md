# 已安装工具快速使用

本页随 0.1.1 工具的 1.2.0800 适配输入安装，可离线阅读。完整准备条件和首次安装步骤见源码根目录的 README.md。

适用组合为 fnOS 1.2.0800、GRID P4-4Q、R535 535.309.01，仍须通过实际文件身份检查。

## 打开菜单

安装后的稳定入口：

```bash
sudo bash /opt/solis-fnos-nvenc/tool/runner.sh
```

保留的源码目录也可使用：

```bash
bash fnos-nvenc.sh
```

密码只在标准 sudo 提示中输入。服务变更前确认所有人退出播放与转码，包括直接播放；提示时输入 `IDLE`。

## 日常操作速查

| 目的 | 操作 |
| --- | --- |
| 检查／安装 | **1** 检查，通过后选 **2** 安装并启用开机检查 |
| 查看状态 | **4** 查看工具版本、自动启用、实际加载与播放验证状态 |
| 验证播放 | 原生 **720p**、一次跳转并继续；保持播放选 **5**，当次声音及同步正常才输入 `AUDIO_OK` |
| 暂停并恢复 | **6** 恢复本次开机基线，保留工具与材料 |
| 更新工具 | 先 **6** 暂停；取得经核查的新源码后选 **3**，再 **1** 检查、**2** 启用 |
| 完整卸载 | 先 **7** 卸载补丁并核对恢复，再 **8** 清理工具及已登记安装残留，保留源码与构建输入 |

播放前在影视服务器设置开启 GPU 加速转码，首选设备明确选为 **NVIDIA GP104GL [Tesla P4]**。库已加载不能代替应用开关或真实 GPU 子进程核对。

## 遇到异常

菜单 **3** 在暂停并核对当前恢复后，登记身份已核实的既有材料，列出仍需核实的路径；更新不会重新启用补丁。私人历史包由维护者另行核对。

出现 `STOP`、恢复未验证、文件身份变化、未登记材料或消费者不明时，保留提示和记录，停止删除或反复覆盖。完整卸载只有残留核对通过才报告完成；历史材料不按目录名或新算哈希直接登记。

当前工具损坏、上一版完整且补丁已暂停时，从保留源码目录执行：

```bash
sudo bash fnos-nvenc.sh restore-tool
```

历史 `check/deploy/status/rollback` 命令保留。`deploy` 仅临时接入，持久补丁启用时不能混用；可用 `bash fnos-nvenc.sh --help` 查看参数。
